# Dashboard, Reports, and Notifications

## Dashboard

Dashboard ต้องตอบก่อนว่าสถานะการเงินปัจจุบันเป็นอย่างไรและวันนี้มีเรื่องใดต้องจัดการ ยอด Wallet เป็นยอดปัจจุบัน ส่วนข้อมูล Income, Expense, Budget และ Fixed Cost อ้างอิง Budget Cycle ปัจจุบัน

เรียงส่วนต่าง ๆ ดังนี้:

1. ยอดรวมทุก Wallet และทางลัดดูแต่ละ Wallet
2. Income และ Expense ของ Budget Cycle ปัจจุบัน
3. Monthly Budget ที่ใช้ไปและเหลือ
4. Attention Item เช่น Fixed Cost ใกล้ครบกำหนดหรือ Budget Allocation ใกล้เต็ม
5. Transaction ล่าสุด

ผู้ใช้ซ่อนตัวเลขการเงินทั้งหมดได้และระบบจำค่าที่เลือกไว้ Dashboard เปรียบเทียบ Expense กับรอบก่อนเฉพาะเมื่อรอบก่อนมีข้อมูลเพียงพอ ลำดับการ์ดคงที่ใน MVP และแต่ละส่วนต้องมี empty state กับทางลัดเริ่มต้นที่เกี่ยวข้อง

## Reports

MVP มีรายงาน Expense แยกตาม Expense Category, Income เทียบ Expense ตามเวลา และ Budget Allocation เทียบยอดใช้จริงกับยอดคงเหลือ

- ตัวเลือกช่วงเวลาคือรอบปัจจุบัน รอบก่อน 3 เดือนล่าสุด และกำหนดช่วงเอง โดยจัดกลุ่มเป็นวัน เดือน หรือ Budget Cycle เมื่อเหมาะสม
- รายงานหมวดแสดง 5 หมวดที่มียอดสูงสุด รวมที่เหลือเป็น “หมวดอื่น” และเปิดดูทุกหมวดโดยเรียงยอดจากสูงไปต่ำได้
- Expense Category ใช้กราฟวงแหวน, Income เทียบ Expense ใช้กราฟแท่ง และ Budget ใช้ progress bar ร่วมกับรายการตัวเลข
- ทุกกราฟต้องมีข้อความประกอบ ไม่ใช้สีเพียงอย่างเดียวในการสื่อความหมาย
- การกดส่วนของรายงานเปิด Transaction ที่กรองตามช่วงเวลาและหมวด พร้อมรักษาตัวกรองเมื่อย้อนกลับ
- เมื่อ Transaction ย้อนหลังถูกเพิ่ม แก้ หรือลบ รายงานคำนวณใหม่ตามข้อมูลล่าสุด แต่แผนของ Budget Cycle ที่ปิดแล้วยังคงแก้ไม่ได้
- MVP ไม่ส่งรายงานเป็นรูปหรือ PDF การส่งออกข้อมูลใช้ CSV ตามสัญญาที่จะกำหนดแยกต่างหาก

## Attention and Notification Rules

Attention Item ไม่เหมือน Notification: Attention Item เป็นสถานะที่ยังต้องจัดการและคงอยู่จนต้นเหตุสิ้นสุด ส่วน Notification เป็นข้อความที่ส่งเพื่อเรียกความสนใจ

### Budget

- เมื่อ Monthly Budget หรือ Budget Allocation ข้าม 80% ให้แสดง Attention Item ภายในแอป แต่ไม่ส่ง Android notification
- เมื่อข้าม 100% ให้แสดง Attention Item และส่ง Android notification
- แต่ละระดับแจ้งครั้งเดียว หากยอดลดต่ำกว่าเกณฑ์แล้วข้ามขึ้นมาใหม่จึงแจ้งซ้ำได้

### Fixed Cost

- ส่ง Android notification ก่อนครบกำหนด 3 วัน ในวันครบกำหนด และครั้งแรกที่เปลี่ยนเป็น Overdue
- Overdue Attention Item คงอยู่จน Fixed Cost Occurrence เป็น Paid หรือ Skipped
- หากมีหลายรายการถึงกำหนดพร้อมกัน ให้รวมเป็น notification เดียวและเปิดไปยังรายการทั้งหมด

### Delivery and Privacy

- ใช้ local Android notifications และศูนย์แจ้งเตือนภายในแอป โดยไม่พึ่ง server
- เวลาส่งเริ่มต้นคือ 09:00 ตามเวลาท้องถิ่นของเครื่องและผู้ใช้เปลี่ยนได้
- กด notification แล้วเปิดรายละเอียดที่เกี่ยวข้อง แต่ห้ามเปลี่ยนเป็น Paid หรือสร้าง Expense จากหน้าจอล็อก
- ค่าเริ่มต้นของ lock screen ซ่อนชื่อรายการและยอดเงิน ผู้ใช้เลือกแสดงรายละเอียดได้ใน Settings
- ขอสิทธิ์ Android notification เมื่อผู้ใช้สร้าง Fixed Cost ที่เปิดแจ้งเตือนเป็นครั้งแรก พร้อมอธิบายประโยชน์ก่อนแสดงคำขอของระบบ
- หากผู้ใช้ปฏิเสธ แอปและศูนย์แจ้งเตือนยังทำงาน พร้อมทางลัดไป Settings และไม่ถามซ้ำทุกครั้ง
- Settings มีสวิตช์ Android notification รวม สวิตช์ Budget และ Fixed Cost และค่าราย Fixed Cost โดยค่ารายการมีความสำคัญสูงสุด
- ข่าวทั่วไปมีสถานะอ่านแล้วหรือยังไม่อ่าน เก็บ 30 วันและล้างได้ ส่วน Attention Item ที่ยังไม่สิ้นสุดล้างไม่ได้
