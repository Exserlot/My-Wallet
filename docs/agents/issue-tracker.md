# Issue tracker: GitHub

Issues and specifications live in GitHub Issues for `Exserlot/My-Wallet`.
Use the `gh` CLI for creating, reading, labeling, commenting on, and
closing issues. Infer the repository from the configured Git remote.

Pull requests are not treated as a triage request surface.

When a skill says "publish to the issue tracker," create a GitHub issue.
When it says "fetch the relevant ticket," read the issue and its comments.
