# Triage Labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human action or judgment |
| `wontfix` | `wontfix` | Will not be implemented |

When a skill refers to a canonical role, apply its corresponding
repository label.
