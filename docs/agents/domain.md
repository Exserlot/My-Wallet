# Domain Docs

This repository uses a single-context domain layout.

Before changing the codebase, read `CONTEXT.md` and any relevant records
under `docs/adr/`. If either location does not exist, proceed silently.

Use terminology defined in `CONTEXT.md` consistently in code, tests,
issues, and documentation. If a proposed change contradicts an existing
ADR, identify the conflict explicitly instead of silently overriding it.
