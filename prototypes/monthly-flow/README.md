# Monthly Flow Prototype

ต้นแบบแบบทิ้งได้สำหรับตอบคำถามใน GitHub Issue #7:

> ประสบการณ์ใช้งานบน Android ควรจัดลำดับหน้าจอและการกระทำอย่างไร เพื่อให้บันทึกด้วยมือได้เร็ว ใช้ Bank Slip เป็นตัวช่วย และเห็นงบกับ Fixed Cost ของรอบปัจจุบันได้ชัดเจน?

เปิด `index.html` ด้วยเบราว์เซอร์ หรือรันจาก repository root:

```powershell
Start-Process .\prototypes\monthly-flow\index.html
```

สลับแนวทางด้วยแถบลอยด้านล่าง ปุ่มลูกศรบนคีย์บอร์ด หรือ URL:

- `?variant=A` — ภาพรวมเดือนเป็นศูนย์กลาง
- `?variant=B` — บันทึกรายการเป็นศูนย์กลาง
- `?variant=C` — งานที่ต้องจัดการวันนี้เป็นศูนย์กลาง

ข้อมูลและการกระทำทั้งหมดเป็นตัวอย่างในหน่วยความจำ ไม่มีการบันทึกลงเครื่อง
