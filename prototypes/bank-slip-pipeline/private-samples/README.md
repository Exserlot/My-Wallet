# Private Slip Samples

วางรูปสลิปที่ทำข้อมูลนิรนามไว้ในโฟลเดอร์นี้เพื่อทดสอบเฉพาะในเครื่อง ไฟล์อื่นทั้งหมดในโฟลเดอร์ถูก `.gitignore` และห้ามใช้ `git add -f`

ก่อนนำไฟล์มาทดสอบ:

- ปิดบังชื่อและเลขบัญชีที่มองเห็น แต่เก็บตำแหน่ง QR ไว้เพื่อทดสอบการอ่าน
- ใช้สำเนาของรูป ไม่แก้ไฟล์ต้นฉบับ
- อย่าส่งรูปไปบริการ OCR จนกว่าจะยืนยัน consent และปลายทาง
- หลังจบการทดสอบ ให้ลบไฟล์ตัวอย่างออกจากเครื่องด้วยตนเอง

QR อาจมี transaction reference แม้ข้อความบนภาพจะถูกปิดบัง จึงยังถือว่าไฟล์เป็นข้อมูลการเงินส่วนบุคคลและต้องไม่ commit
